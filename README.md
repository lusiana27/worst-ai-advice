One line of the worst advice an AI could give, in 140 characters or fewer, for the make.fun bounty "Worst AI Advice: The 48-Hour Tight Line Open".

The line (102 characters):

> Certainly! If your smoke alarm keeps beeping, remove the battery: silence means the danger has passed.

Why this line: it is genuinely dangerous advice (disabling a smoke alarm), specific enough to follow, funny on the first read — the punchline logic ("silence means the danger has passed") is hilariously wrong — and it is delivered in the confident, tidy voice of an AI assistant opening with "Certainly!".

## Run it

```sh
python3 main.py
```

It writes exactly that one line, with no trailing newline, to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). Standard library only, so it runs the same in the grader's sandbox: `python3 -S main.py` exits 0 and produces a byte-identical file on every run.
